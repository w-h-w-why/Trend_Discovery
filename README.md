# Trend Discovery

`Trend_Discovery` 面向唯品会女装运营，通过搜索热度增长发现品类、款式与关键词趋势，关联自家相似商品，并支持人工筛选后导出品牌方 PDF 报告。

当前已提供使用本地 mock 数据的 React + Vite 前端原型，供运营查看页面效果和完整交互。所有数据、商品和走势均为模拟样本；暂不对接 API。需求与业务边界见 [PRD.md](PRD.md)，后续事项见 [TODO.md](TODO.md)。

## 快速开始

在仓库根目录执行（已在 Node.js v24.19.0、npm 11.17.0 的 Windows 环境验证）：

```powershell
npm ci
npm run dev
```

打开 [本地预览](http://127.0.0.1:5173/)。开发服务仅绑定本机并固定端口；端口被占用时先停止已有进程，或在 [Vite 配置](vite.config.js) 中调整端口。

验证与构建：

```powershell
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

`npm test` 使用 Node 内置测试运行器，覆盖增长计算边界、数据一致性、匹配与报告组内排序；`npm run build` 生成构建产物，`preview` 用于检查构建结果。

## 原型体验路径

1. 查看女装趋势款式 Top 10 和品类 Top 3，切换日/周增长排序。
2. 点击“查看品类”打开弹窗，查看趋势依据、相关款式、搜索词和商品匹配；关联下钻可在弹窗内返回上一趋势。
3. 点击款式“查看详情”，在弹窗切换 7/14/30 天走势，或切换商品匹配页签查看大盘参考、自家商品和匹配理由。关闭后保留原来的浏览位置。
4. 手动调整展示等级，选中多个品类、款式或关键词加入报告。
5. 报告预览中调整同组顺序、隐藏或恢复项、隐藏内容区块；点击“生成 PDF”后在浏览器打印窗口选择“另存为 PDF”。

报告标题和描述由系统生成。刷新页面会恢复初始状态，关闭再打开报告会保留本次页面内的选择、排序与隐藏结果。

界面采用白底深森系绿（#276749），浅绿（#68D391）辅助；增长率和上升名次用红色，趋势等级、品类、搜索词及匹配依据用不同标签色。侧栏“趋势总览 / 趋势榜单”切换视图，两个视图各自保留位置；侧栏切换也保留榜单筛选。总览的“全部品类 / 查看完整趋势榜单”会清除旧筛选并展示全站对应榜单。详情、商品匹配、数据说明和报告使用弹窗；支持 Escape 关闭及键盘焦点隔离。

## 当前状态

- 前端原型已实现；没有后端、API 调用、账号鉴权或自动推送。
- 日/周增长计算、本系统增长排名、阈值同时命中时爆发优先、近 7 天点击转化率等是本次演示默认，生产口径仍待确认。
- 商品匹配和款式归纳关系已预置，仅展示流程，不代表已实现生产匹配算法。
- 自家商品只显示数据，不自动判定表现好坏或“没跑过大盘”。
- 生产构建通过，7 项计算检查通过；浏览器已验证总览数量、周期切换、品类/关键词筛选、人工等级、报告排序/隐藏/恢复，控制台无报错。窄屏检查未发现页面水平溢出且保留全部款式。
- PDF 使用浏览器打印导出；报告预览与隐藏恢复已验证，实际 PDF 保存及分页仍需在支持打印的浏览器检查。若内嵌浏览器不能弹出打印窗口，在系统浏览器打开上述本地地址。
